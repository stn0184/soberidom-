# СобериДом — дизайн (как это выглядит)

Тон, портрет пользователя и запрет жаргона — `UX_PRINCIPLES.md`; здесь —
визуальный язык, состояния экранов и инвентарь компонентов. Проверка
каждого экрана — вопросом из `UX_PRINCIPLES.md` §0: «Поймёт ли это
парикмахер, впервые зашедший на сайт? Не испугается ли?»

## 1. Визуальный язык

- **Дизайн-система:** shadcn/ui на `radix-ui`, примитивы только из
  `src/components/ui/`; второй UI-kit не заводим.
- **Тема:** slate + amber-600 как primary; цвета только через токены
  Tailwind v4 из `src/app/globals.css` (`bg-primary`, `text-muted-foreground`,
  `bg-card`…), не палитрой и не hex. Тёмная тема через `next-themes`.
- **Типографика:** Inter (cyrillic) через `next/font`, `--font-sans`;
  заголовки тем же шрифтом (`--font-heading`). Основной текст `text-sm`
  в карточках, `text-base` в контенте шага.
- **Иконки:** Lucide, размер по умолчанию `size-4`, в карточках-разделах
  `size-7`/`size-8` с `text-primary`.
- **Кнопки:** шкала из спеки 001 — `default` 36px, `lg` 44px, `xl` 48px
  для главных CTA публичных страниц; в плотных местах (админка, тулбары)
  `sm`/`icon-sm` 32px. Мобильный таргет не меньше 44px.
- **Цвета этапов стройки:** `stages.color` ∈ red/green/yellow/blue/
  orange/purple — кружок-маркер в сайдбаре конструктора и на карте
  этапов; та же маркировка в раскрое.
- **Плотность:** карточки `Card` с `gap-4`; сетки разделов
  `sm:grid-cols-2 lg:grid-cols-3`; телефон — одна колонка, боковой отступ
  16px, без горизонтального скролла.
- **Деньги:** символ валюты, не код — `₽`, `₸`, `Br` (неизвестная валюта —
  код); формат один на всё приложение, `formatMoneyMinor` в
  `src/lib/utils.ts`. Цена за куб у пиломатериала — второй строкой под
  ценой за штуку, серым, без копеек: «≈ 26 444 ₽/м³». Позиция без цены —
  прочерк и бейдж «цена уточняется», не «0 ₽»; в итог не входит, итог
  подписан «без N позиций без цены» (прототип 003).
- **Выбор из вариантов** — радио-карточки в ряд (`sm:grid-cols-2
  lg:grid-cols-3`): кружок-радио, название, бейдж, цена, короткая
  пометка серым, описание; действующая подсвечена `ring-2 ring-primary`
  с подписью-состоянием («Ваш выбор» / «Советуем новичку»). Настоящий
  ноль в цене — слово «Бесплатно», не «0 ₽» и не прочерк (прочерк — для
  неизвестной цены). Аренда — всегда итогом «N ₽/сут × M дн. ≈ сумма»
  с подписью «если брать на весь срок» (прототип 004).
- **Чипы этапов** — человеческие имена, не коды; все этапы проекта →
  один чип «На всей стройке», пять и больше → четыре чипа и «ещё N».
- **Одна главная кнопка на экране** (`xl`), остальные переходы — текстовые
  ссылки со стрелкой («Смета целиком →»). Шапка экрана раздела — в два
  яруса: надстрока-контекст («● Этап 3 · Стены» + чипы), ниже `h1`
  с человеческим названием и вводный текст.

## 2. Шесть состояний экрана

Правило проекта (CLAUDE.md, инвариант 8) требует три состояния на каждом
экране; для нового экрана разбираются все шесть **до** вёрстки:

1. **Загрузка** — `Skeleton` по форме будущего контента, не спиннер.
2. **Пусто** — объяснение и действие («У вас пока нет проектов» + CTA
   «Подобрать дом»), а не нули и прочерки.
3. **Ошибка** — `Alert` с человеческим текстом из `ru.ts` и кнопкой
   «Повторить».
4. **Мало данных** — один этап, одна позиция сметы: экран не выглядит
   сломанным.
5. **Много данных** — 45 шагов, сотни позиций сметы: sticky-итоги,
   группировка, `Collapsible`.
6. **Штатно** — обычный случай.
