# 001 — Крупные кнопки по всему сайту

Источник: пометка pins `19c1d079` на `/` — «увеличим кнопки на сайте все».
Тип: дизайн. Приоритет: обычно.

**Статус:** в работе — код готов и на проде, ждёт визуальной приёмки владельца
**Размер:** S
**Зависит от:** ничего
**Прототип:** не нужен

## Проблема

Шкала размеров в `src/components/ui/button.tsx` унаследована от компактной
сборки shadcn: `default` = h-8 (32px), `lg` = h-9 (36px). Главный CTA лендинга
(`size="lg"`) всего на 4px выше рядовой кнопки — визуально не читается как
призыв к действию, а на телефоне попадает пальцем хуже рекомендованных 44px.

Целевая аудитория продукта — люди без опыта стройки, значительная часть
трафика мобильная. Мелкий таргет здесь стоит дороже, чем плотность интерфейса.

## Решение

Поднять всю шкалу на один шаг и добавить `xl` для главных CTA публичных
страниц. Значения (высота → высота):

| size      | было   | стало  |
|-----------|--------|--------|
| xs        | h-6    | h-7    |
| sm        | h-7    | h-8    |
| default   | h-8    | h-9    |
| lg        | h-9    | h-11   |
| xl (нов.) | —      | h-12, text-base |
| icon      | size-8 | size-9 |
| icon-xs   | size-6 | size-7 |
| icon-sm   | size-7 | size-8 |
| icon-lg   | size-9 | size-11 |

Горизонтальные паддинги растут пропорционально: `lg` получает px-5, `xl` — px-6,
`default` — px-3. У `xl` иконки size-5.

На лендинге hero-CTA и финальный CTA переводятся с `size="lg"` на `size="xl"`.

## Область

- `src/components/ui/button.tsx` — шкала `size`, новый вариант `xl`.
- `src/app/(public)/page.tsx` — два CTA на `size="xl"`.
- Остальные 49 файлов с кнопками не правятся: они подхватывают новую шкалу
  автоматически. Плотные места (админка, тулбары) используют `sm`/`icon-sm`,
  которые остаются компактными (h-8 / size-8).
