# Прототип 004 — инструменты с вариантами

**Статус:** одобрен 17.09.2026
**Режим:** витрина

**Что одобрено:** раздел «Инструменты» — потребность с шапкой (название,
зачем, чипы этапов человеческими именами, «Нужен ≈ N дн.») и
радио-карточками вариантов бок о бок, без сворачивания; Stat-Card
«Купить / Арендовать ≈ … по вашему выбору»; подсветка «Ваш выбор» /
«Советуем новичку»; «Бесплатно» вместо «0 ₽»; аренда итогом
«N ₽/сут × M дн. ≈ сумма». Админка — вкладка «Инструменты» с таблицей
и красным бейджем «нет варианта для новичка». Пустые состояния.
**Три уточнения владельца:** на экране этапа — только потребности,
впервые нужные на этом этапе, остальные строкой «Уже должны быть у
вас: …»; аренда с подписью «если брать на весь срок»; «Выбрать другой →»
только при двух и более вариантах. Внесены в спеку и `design.md` §1.
**Спека:** `specs/004-инструменты-с-вариантами/spec.md`
**Адрес:** http://localhost:3000/prototype/004 (только `npm run dev`)

## Как посмотреть

```
npm run dev
```

Открыть http://localhost:3000/prototype/004. Вверху — переключатель
четырёх экранов: **Инструменты · Экран этапа · Админка · Пусто**.

Страница живёт в `src/app/prototype/004/` и существует только в режиме
разработки: в проде `notFound()`. Прод-код не тронут — маршрут файловый,
регистрировать ничего не пришлось. Моки — в `src/app/prototype/004/mock.ts`,
запросов к базе нет ни одного.

## Что на экранах

| Экран | Что показано |
| --- | --- |
| Инструменты | `/my/[id]/tools` целиком: две Stat-Card «Купить ≈ 25 900 ₽» / «Арендовать ≈ 6 000 ₽» с подписью «по вашему выбору», фильтр по категории, 15 потребностей из сида; у каждой — заголовок, «зачем», чипы этапов и «нужен ≈ N дн.», ниже варианты радио-карточками (1–3 в ряд). Подсвечены: «Ваш выбор» у двух потребностей (ножовка вместо циркулярки, мотобур вместо лопаты), «Советуем новичку» у остальных |
| Экран этапа | Блок «И это понадобится» на этапе «Стены»: 13 потребностей по одной строке — название, действующий вариант, бейдж, цена, подпись «ваш выбор»/«советуем новичку», справа «Выбрать другой →». Таблица материалов заглушена: она одобрена прототипом 003 и не меняется |
| Админка | «Этапы и шаги» → новая вкладка «Инструменты»: таблица 15 потребностей (название, категория, этапы, число вариантов), кнопка «Добавить», меню строки; у «Крепить мембраны и плёнки» — красный бейдж «нет варианта для новичка» |
| Пусто | `/tools` без инструментов («Список инструментов пока пуст») и та же вкладка админки без строк («У проекта ещё нет инструментов» + «Добавьте первую потребность») |

Ничего не работает: карточки вариантов не кликаются, фильтр не
фильтрует, кнопки — картинка. Выбор **нарисован**, а не сохраняется:
экран показывает, как выглядят «ваш выбор» и «советуем новичку», а не
как они переключаются.

## Решения, принятые в прототипе

- **Чипы этапов — человеческими названиями**, не кодами (`Стены`, а не
  `walls`). Сейчас `tools-view.tsx` печатает код из базы. Нужен словарь
  `ru.build.stageCodes` — в спеке его нет.
- **Потребность «на всех 11 этапах» — один чип «На всей стройке»**, а не
  11 бейджей; при 5+ этапах — 4 чипа и «ещё N». Иначе шапка карточки
  длиннее самих вариантов.
- **Цена 0 ₽ пишется словом «Бесплатно»** (правило 3-4-5 рулеткой).
  «0 ₽» в проекте запрещён (`design.md` §1), но здесь ноль настоящий, а
  не отсутствие цены — прочерк соврал бы.
- **Аренда показана итогом:** «Аренда 700 ₽/сут × 52 дн. = 36 400 ₽».
  Без итога человек не увидит, что аренда торцовки дороже покупки пилы —
  ради этого расчёт и затевался.
- **Ссылки «Выбрать другой →» нет у потребностей с одним вариантом** —
  выбирать не из чего; спека даёт ссылку каждой строке.
- **«Нужен ≈ N дн.» вынесено в шапку потребности** — иначе число дней в
  формуле аренды выглядит взявшимся ниоткуда.
- **Радио-карточка** — кружок с галочкой слева от названия, бейдж
  рекомендации справа, цена жирным, `speed_note` серым, ниже описание,
  внизу бейдж «Для новичка» и подпись «Ваш выбор»/«Советуем новичку».
  Подсветка — `ring-2 ring-primary`.
- **Текст ru.ts заново:** `ru.tools.*` переписан (новый `intro`,
  `buyTotal` → «Купить ≈», `chosen`, `advised`, `beginnerBadge`,
  `free`, `rentPrice`); старые `alternative`, `price`, `rent` уходят.
  Все строки прототипа — в `mock.ts` как будущие ключи.

## Куда смотреть в первую очередь

1. **Длина экрана `/tools`.** 15 потребностей × до трёх карточек — это
   примерно шесть экранов прокрутки. Фильтр по категории спасает
   наполовину. Если это много — самое дешёвое лечение — свернуть
   невыбранные варианты (`Collapsible` «ещё 2 варианта»), но тогда
   пропадает главное: сравнение бок о бок.
2. **13 строк «И это понадобится» на этапе «Стены».** Инструменты,
   нужные всю стройку (рулетка, СИЗ, удлинитель, шуруповёрт), повторяются
   на каждом этапе. Может быть, на этапе нужны только те, что появились
   впервые, а остальные — одной строкой «и всё, что уже куплено».
3. **Аренда × дни.** «Нейлер 1 500 ₽/сут × 25 дн. = 37 500 ₽» —
   арифметика честная, но человек так не арендует: он берёт нейлер на
   три дня. Спека считает дни как сумму длительностей этапов; цифра
   подталкивает к покупке, но выглядит пугающе. Стоит решить: так и
   оставить или подписать «если брать на весь срок».
4. **Красный бейдж «нет варианта для новичка»** — в таблице он кричит
   громче названия потребности. Проверить, что это уместно.
