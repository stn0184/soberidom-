# Архив прототипов

Прототип закрытого этапа переезжает сюда папкой целиком,
`git mv prototype/<папка> prototype/archive/<папка>` в том же коммите,
что закрывает этап. Ворота проверяют, что не осталось наоборот.

Это свидетельство: человек видел визуал до кода и одобрил его. Не второй
источник правды — разошёлся с приложением, прав приложение.
