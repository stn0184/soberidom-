# Прототип 003 — закупки перед этапом

**Статус:** одобрен 17.09.2026
**Режим:** витрина

**Что одобрено:** порядок экрана — двухъярусная шапка (надстрока
«● Этап 3 · Стены» + чип длительности, ниже `h1` и intro), таблица
материалов с прогрессом «Куплено X из Y», ₽/м³ второй строкой у
пиломатериала, подсказка о хранении иконкой, «Итого по этапу» под
таблицей, карточки инструментов с бейджами и альтернативой, одна главная
кнопка `xl` «Начать этап →», остальные переходы — текстовые ссылки.
Пустое состояние — один текст со ссылкой на смету, кнопка остаётся.
Без региона — выбор города на месте таблицы, инструменты видны.
Решено по замечаниям сборщика: валюта — символом везде (правило
`design.md` §1), позиция без цены — прочерк и бейдж «цена уточняется»,
в итог не входит, итог подписан «без N позиций без цены».
**Спека:** `specs/003-закупки-перед-этапом/spec.md`
**Адрес:** http://localhost:3000/prototype/003 (только `npm run dev`)

## Как посмотреть

```
npm run dev
```

Открыть http://localhost:3000/prototype/003. Вверху — переключатель трёх
состояний: **Штатно · Пусто · Без региона**.

Страница живёт в `src/app/prototype/003/` и существует только в режиме
разработки: в проде `notFound()`. Прод-код не тронут — маршрут файловый,
регистрировать ничего не пришлось. Моки — в `src/app/prototype/003/mock.ts`,
запросов к базе нет ни одного.

## Что на экранах

| Состояние | Что показано |
| --- | --- |
| Штатно | Этап 3 «Стены»: сайдбар конструктора, шапка (маркер, «Этап 3 · Стены», intro, чип «≈ 6 дн.»), «Перед этапом купите» — 6 позиций с прогрессом «Куплено 2 из 6», ₽/м³ под ценой у двух пиломатериалов, storage_tip иконкой; «И это понадобится» — 3 инструмента; кнопка `xl` «Начать этап →» и ссылка «Смета целиком →» |
| Пусто | Ни BOM, ни инструментов: один текст вместо двух блоков, ссылка на смету, кнопка «Начать этап →» остаётся |
| Без региона | Вместо таблицы — объяснение и выбор города с кнопкой «Сохранить»; инструменты видны |

Ничего не работает: галочки, кнопки и ссылки — картинка. Выбор города —
внешний вид `RegionCombobox`, список не открывается (в базу не ходим).
